OpenMeeting Gateway is an open-source, self-hosted alternative to Recall.ai, designed to enable AI agents to join, listen, speak, and interact in online meetings.

The project aims to provide:

- Automated meeting bot management.
- Real-time bidirectional audio streaming.
- Google Meet, Microsoft Teams, and Zoom integration.
- Native LiveKit integration.
- Participant identification and speaker tracking.
- Real-time transcription and meeting chat interaction.
- Multi-agent and multi-bot support.
- REST API, WebSocket, and MCP interfaces.
- Docker-based deployment and session isolation.
- Compatibility with Gemini Live and other real-time AI models.

The goal is to eliminate dependency on proprietary meeting bot infrastructure while providing developers with full control over their data, deployment, and AI integrations.
